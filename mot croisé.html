Grille de mots croisés

Choisis une taille, clique une case pour écrire une lettre, appuie sur espace pour poser ou retirer une case noire.

Grille en texte

Un point = case blanche vide, un dièse (#) = case noire, une lettre = case remplie. Les lignes « SEP 3,5,D » indiquent un trait pointillé à droite de la case ligne 3, colonne 5 (« B » = en dessous). Les lignes « H3 : … » ou « V5 : … » contiennent les définitions. Modifie le texte puis clique sur « Charger cette grille » pour l'appliquer — les dimensions s'ajustent automatiquement au texte collé.

    Verticalement

      Astuce — clique une case pour la sélectionner, reclique dessus pour passer d'horizontal à vertical. Tape une lettre pour l'écrire, les flèches pour te déplacer, retour arrière pour effacer. Espace ou « . » bascule une case noire (la sélection avance sans jamais traverser une case noire). Clique le numéro d'un mot dans les définitions pour t'y rendre directement. « - » ou « / » trace (ou retire) un trait pointillé entre la case précédente et la case sélectionnée, pour séparer deux mots d'une même réponse. « Télécharger version imprimable » enregistre un fichier HTML sobre (grille en haut, définitions numérotées en dessous) — ouvre-le puis utilise Ctrl/Cmd+P pour l'imprimer ou l'enregistrer en PDF.
